# Level 4: FRB Isotropy Test With Jackknife Errors

This document describes the Level 4 pipeline implemented in `code4_jackknife.py`
and used by `frb_isotropy_analysis.ipynb`.

Level 4 extends the improved Level 3 analysis by adding jackknife error bars to:

- the angular two-point correlation function, `w(theta)`;
- the coarse-bin absolute amplitude statistic, `|<w>|`.

The null hypothesis, `H0`, is still based on a multi-survey empirical selection
function. The jackknife layer estimates how stable the observed signal is under
leave-one-sky-region-out resampling.


## 1. Input Catalog

The pipeline reads:

```python
ALL_FRB_PATH = ".../FRB_catalogs/SkyPosition.csv"
```

The required columns are:

- `RA`
- `DEC`
- `Reporting_Group_s`

The catalog is loaded with:

```python
df_data = apply_mask(load_catalog(ALL_FRB_PATH))
```

`load_catalog()` standardizes column names and keeps only the relevant columns.


## 2. Galactic Mask

The first mask removes FRBs close to the Galactic plane:

```python
GAL_CUT = 20.0
```

The code converts each FRB from equatorial coordinates `(RA, DEC)` to Galactic
coordinates and keeps only:

```text
|b| > 20 deg
```

This produces the masked observational catalog used in all later steps.

Important: the same Galactic mask is also applied to the HEALPix selection
function maps. Pixels inside the masked Galactic band are assigned zero
selection probability.


## 3. Survey Split

The column `Reporting_Group_s` identifies which survey or reporting group is
associated with each FRB.

The function:

```python
split_by_survey(df_data)
```

creates one subcatalog per survey label.

If a source has multiple labels separated by commas, for example:

```text
ATLAS, Pan-STARRS, GaiaAlerts
```

the same source is assigned to each listed survey. This is why survey weights
are computed from total survey memberships, not simply from the number of unique
FRBs.


## 4. Survey Weights

Each survey receives a mixture weight:

```python
survey_weights[name] = len(subdf) / total_memberships
```

So the weight is the fraction of masked detections associated with that survey.

For example, if CHIME contributes about 93% of the masked catalog, then the
effective null model is CHIME-dominated:

```text
SF_total ~= 0.93 * SF_CHIME + smaller survey components
```

These weights are empirical detection fractions. They are not independent
measurements of observing time, beam sensitivity, fluence threshold, or exposure.


## 5. Empirical Selection Functions

For each survey, the code builds a HEALPix sky map:

```python
build_selection_function_improved(...)
```

The steps are:

1. Convert FRB coordinates to HEALPix pixels.
2. Count how many FRBs fall in each pixel.
3. Convert counts into a probability map.
4. Estimate a diagonal Poisson uncertainty for the map.
5. Smooth the map with a Gaussian kernel.
6. Apply the Galactic mask.
7. Renormalize the map so the total probability is 1.

The main resolution/smoothing parameters are:

```python
NSIDE_SF = 64
SMOOTH_SIGMA = 5.0
```

`NSIDE_SF` controls the HEALPix resolution. Higher values mean smaller pixels.

`SMOOTH_SIGMA` controls how strongly the empirical map is smoothed, in degrees.
Small smoothing keeps the SF close to the observed FRB positions. Large smoothing
spreads detections over wider angular scales.


## 6. Selection Function Uncertainty

The pipeline treats the empirical SF as uncertain.

For each survey map, it estimates a diagonal Poisson variance:

```python
sf_cov_diag
```

Then, when generating H0 mocks, it can perturb the nominal SF:

```python
generate_sf_variant(...)
```

This creates plausible alternative selection functions within the estimated
Poisson uncertainty. The H0 mock ensemble therefore includes:

- Poisson-like uncertainty in the empirical selection function;
- isotropic sampling noise under that selection function.


## 7. Random Catalogs And H0 Mocks

Mock catalogs are generated by:

```python
generate_mixture_catalog_improved(...)
```

For each mock FRB, the algorithm does two things:

1. Select a survey using the survey weights.
2. Draw a sky position from that survey's selection function.

So the effective null distribution is:

```text
SF_total(sky) = sum_s weight_s * SF_s(sky)
```

This is not a perfectly uniform sky. It is an instrument-mixture null model.

The H0 ensemble is generated by:

```python
run_ensemble_mocks(...)
```

The default is:

```python
N_ENSEMBLE = 10
N_MOCKS_PER_ENSEMBLE = 20
```

That gives 200 H0 mocks, grouped across 10 perturbed selection-function variants.


## 8. Angular Two-Point Correlation Function

The code computes the angular two-point correlation function using TreeCorr:

```python
compute_2pacf(df_data, df_rand)
```

It uses the Landy-Szalay estimator through TreeCorr's `calculateXi` machinery.

The current angular range and binning are:

```python
MIN_SEP = 0.5
MAX_SEP = 180.0
BIN_SIZE = 5.0
```

With linear binning, this gives about 35 angular bins. This coarser binning is
intentional: it makes the covariance estimated from H0 mocks more stable than
the previous fine binning with about 99 bins.

The result is:

```python
theta, w_obs
```

where:

- `theta` is angular separation in degrees;
- `w_obs` is the observed angular correlation function.

The H0 mocks produce an ensemble:

```python
all_w_h0
```

The plots show the H0 mean and the 1 sigma, 2 sigma, and 3 sigma bands.


## 9. Absolute Sum Statistic

The code also compresses `w(theta)` into coarse angular bins:

```python
COARSE_BINS = np.arange(0, 181, 20)
```

For each coarse bin, it computes:

```text
| mean(w(theta)) |
```

This produces:

```python
abs_obs
```

and, for mocks:

```python
all_abs_h0
```

This statistic tracks the absolute amplitude of angular anisotropy in broad
angular ranges.


## 10. Jackknife Error Bars

Level 4 adds jackknife errors.

The sky is divided into coarse HEALPix regions using:

```python
NSIDE_JACKKNIFE = 4
```

Each observed FRB is assigned to one jackknife region:

```python
assign_jackknife_regions(...)
```

Then the code repeatedly removes one populated sky region at a time:

```python
_run_one_jackknife_region(...)
```

For each leave-one-region-out sample, it recomputes:

- `w(theta)`;
- `|<w>|`.

The jackknife covariance is:

```text
C = (N_regions - 1) / N_regions * sum_i [(x_i - mean(x)) (x_i - mean(x))^T]
```

The plotted jackknife error bars are:

```text
sqrt(diag(C))
```

The jackknife does not define H0. It estimates observational stability of the
measured signal under removal of sky regions.


## 11. Statistical Tests

The main statistical comparison is:

```python
compute_statistics(...)
```

It computes:

- `chi2`;
- `chi2/dof`;
- analytic chi-square p-value;
- empirical p-value from mocks;
- sigma-equivalent from empirical p-value;
- RMS normalized deviation;
- absolute-amplitude empirical p-value.

The empirical p-value is generally preferred:

```text
p_empirical = (number of mocks more extreme than observed + 1) / (N_mocks + 1)
```

With 200 mocks, the smallest possible empirical p-value is:

```text
1 / 201 ~= 0.004975
```

Therefore, if the output is `p_empirical = 0.004975`, it means no mock was more
extreme than the observation. It does not mean the true p-value is known more
precisely than that.


## 12. Sensitivity Analysis

If Level 4 is run with:

```python
main_level4(run_sensitivity=True)
```

the code runs:

```python
run_empirical_sensitivity_analysis(...)
```

This tests multiple combinations of:

```python
NSIDE_SF_RANGE = [32, 64, 128]
SMOOTH_SIGMA_RANGE = [3.0, 5.0, 8.0, 10.0]
```

For each pair `(NSIDE, smooth_sigma)`, it:

1. rebuilds the selection functions;
2. recomputes the observed `w(theta)`;
3. generates H0 mocks;
4. computes empirical p-values;
5. saves the table to:

```text
Level4_sensitivity_empirical.csv
```

This is used to assess whether the result depends strongly on arbitrary
selection-function resolution or smoothing choices.

## 16. Important Caveats

This pipeline is designed to be transparent and diagnostic, but several caveats
matter scientifically:

1. The selection functions are empirical.

They are inferred from the observed FRB positions themselves, not from fully
independent instrumental exposure maps.

2. The catalog is CHIME-dominated.

The effective H0 selection function is mostly controlled by CHIME because CHIME
contributes most of the masked detections.

3. Low-weight surveys are noisy.

Surveys with very few FRBs produce localized empirical SF islands after
smoothing. These are nuisance corrections, not robust independent footprints.

4. Jackknife regions are equal-area, not equal-count.

HEALPix provides equal-area sky regions, which is geometrically natural.
However, because the observed FRB density is uneven, some jackknife regions can
contain many more FRBs than others.

5. Empirical p-values are limited by the number of mocks.

With 200 mocks, the smallest possible p-value is about 0.005. More mocks are
needed to resolve smaller p-values.

6. Sensitivity chi-square values can be unstable when mocks are few.

If the number of mocks is comparable to the number of `w(theta)` bins, the
covariance matrix is noisy. In that case, empirical p-values and coarse
statistics should be interpreted more carefully than raw `chi2/dof`.


## 17. Scientific Interpretation

The Level 4 analysis asks:

> Is the observed FRB sky compatible with an H0 sky drawn from the same
> multi-survey empirical selection function, once selection-function uncertainty
> and jackknife observational errors are included?

A robust result should satisfy three conditions:

1. the observed `w(theta)` is unusual relative to H0 mocks;
2. the signal is not erased by jackknife errors;
3. the conclusion is not driven by one arbitrary choice of `NSIDE` or
   `smooth_sigma`.

Level 4 is designed to make those three checks visible.
